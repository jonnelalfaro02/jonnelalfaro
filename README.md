# Credit Repair Portfolio

A clean, professional portfolio website showcasing real credit repair results across Equifax, Experian, and TransUnion.

## Features

- Responsive design (mobile + desktop)
- Documented before/after score case studies
- Process explanation
- Contact form (demo — connect to your preferred service)
- Pure HTML, CSS & JavaScript — no frameworks required

## How to use on GitHub Pages

1. Create a new repository on GitHub (e.g. `credit-portfolio` or `yourname.github.io`)
2. Upload these three files (or push via git):
   - `index.html`
   - `styles.css`
   - `script.js`
3. Go to **Settings → Pages**
4. Under "Source", select the branch (usually `main`) and folder `/ (root)`
5. Save — your site will be live at `https://yourusername.github.io/repo-name`

## Customization

| What to change              | Where                          |
|----------------------------|--------------------------------|
| Your name / brand          | `index.html` (logo + titles)   |
| Email address              | Search for `you@email.com`     |
| Case study numbers         | Results section in `index.html`|
| Colors                     | CSS variables at top of `styles.css` |

## Contact Form

The form is currently a demo. To make it work:

- **Formspree**: Replace the form `action` and add your Formspree endpoint
- **EmailJS**: Add their script and configure
- **Netlify Forms**: Add `netlify` attribute if hosting on Netlify
